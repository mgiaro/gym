# Corpo Libero di Casa

App di allenamento a corpo libero per tutta la famiglia: sedute da 7 a 30 minuti, cinque giorni a settimana, con timer, guida animata per ogni esercizio, profili separati e diario.

## Aprirla e installarla sul telefono

1. Apri il link GitHub Pages del repository (Settings → Pages).
2. **iPhone (Safari):** tocca Condividi → *Aggiungi alla schermata Home*.
3. **Android (Chrome):** menu ⋮ → *Installa app* oppure *Aggiungi a schermata Home*.

Dopo la prima apertura funziona anche senza connessione. I dati (profili, livelli, diario) restano sul telefono di chi la usa; dalla sezione Diario si può copiare una copia di sicurezza.
